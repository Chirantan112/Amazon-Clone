# Amazon Clone

A responsive front-end recreation of the Amazon homepage built with **HTML5 and CSS3**.

## ✨ Features
- Amazon-inspired navigation header with search, location, language, account, orders, and cart sections
- Category navigation panel with hover states
- Hero banner with Amazon India call-to-action
- Product/category card grid
- Multi-section footer inspired by Amazon's desktop layout
- Font Awesome icons via CDN
- Centralized image assets in `assets/images/`

## 🛠️ Tech Stack
- **HTML5** — page structure
- **CSS3** — layout, styling, hover effects, and visual design
- **Font Awesome** — UI icons via CDN

## 🚀 Run Locally
No build tools or dependencies are required.

```bash
git clone https://github.com/Chirantan112/Amazon-Clone.git
```

Then open `index.html` in a browser, or use the **Live Server** extension in VS Code.
